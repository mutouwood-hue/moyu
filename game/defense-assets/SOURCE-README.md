# 《摸鱼防线》2D 美术与音效素材包 — V1 基准

## 内容
- `01_art_direction/` 8 张原创角色、动作、场景、UI、全素材参考图（美术基准）。
- `02_characters/` 蓝方士兵、普通僵尸与五个 Boss 的独立裁切候选图及部分动作帧。
- `03_weapons/` 12 种武器图鉴图标的参考裁切图。
- `04_gates/` 4 类可缩放透明数字门底板，数字需要游戏运行时渲染。
- `05_supply/` 3 类透明武器箱（颜色用于物件主题，不应提前暴露随机品质）。
- `06_environments/` 五章 960×1200 的可缩放伪透视道路背景 SVG+PNG。
- `07_effects/` 12 类战斗效果的参考裁切图。
- `08_ui/` 基础图标的 SVG+PNG。
- `09_audio/` 20 种原创合成音效 + 2 条原创循环音乐示意。
- `10_design/` 结构化规则与本素材包状态。

## 重要质量说明
本包的原始 AI 角色图和动作图集已确立画风，但**不能视为已经完成逐帧一致性和可直接上架的游戏动画**。部分裁切还带有非透明的底色、阴影或周边帧污染；武器图标和效果图也是来源裁切，需要在 Work 中进行精修、透明度修正、统一锚点、图集导出和视觉 QA。部分程序生成 SVG 属于轻量运行素材基底，最终可按审定美术提升。

### 本项目的动作图集
`enemy-*-walk-atlas.png` 是按现有角色设计生成的五套透明四帧步行动画，`boss-*-attack-atlas.png` 是五套对应首领的透明四帧攻击动画。每张图按四列等宽取帧；首领出招帧由游戏的攻击预警时间驱动，敌人按时间循环行走。素材保留原始角色裁切文件作为后备。图集已逐张检查动作、透明背景和帧边界；游戏中在加载时缩小图集以控制渲染开销。

目前已覆盖全游戏各素材类别，但仍需 Work 依据实际仓库完成最终生产化。不要将展示板直接作为一张游戏贴图；不要把表现示意当成可玩的战斗实现。

## 待确认仅限实现层
- 现有 Electron 游戏窗口的真实尺寸、PixiJS/Canvas 接入方式、主软件设计 token。
- 实际存档接口、老板键处理与主软件奖励货币边界。

## 已锁定的美术与玩法
- 伪透视 2D；高密度军队观感 + 圆润 Q 版角色。
- 原软件融合式大厅 UI；游戏内独立美术。
- 士兵自动向前、横向移动，自动射击 + 有界角度辅助；数字门不能误射其他车道。
- 数字门通过后才概率出现武器箱，射击击破才有奖励；小人数收益侧平均更容易出现好箱。
- 六种普通敌人、五章五 Boss、30 关、无尽模式；全部功能一次性交付。
- 军队科技+武器图鉴精研；四槽自动替换；战术技能自动施放。
- 普通僵尸接触减员、Boss 预警范围攻击；士兵归零失败一键重试。
- 无尽模式每五波检查点可恢复，但不能利用检查点死亡复活。
- 所有数值平衡是调试参数，不是需要重新逐项确认的需求。
